# ElectronicTinkerStuff
A little Repository with all our small electronic projects

## PCBs
**All circuit boards are available for free use under the MIT License. If you use them directly without significant modifications, I would simply ask that you leave the name of the organization (Lichtwerkstatt) and the designer (Canan Gallitschke) on the circuit boards.**

A collection of all our self-designed PCBs. Included for each PCB are:
- KiCad files
- SVG graphics
- Gerber files for JLCPCB

The “footprints” folder contains all custom footprints. 

The Excel file “Teileliste.xls” contains a list of the required components and purchase links for most PCBs.

For each board, there is a “production” folder containing a ZIP file with the Gerber files. This ZIP file can be uploaded directly to JLCPCB for production.
